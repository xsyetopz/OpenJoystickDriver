Audit baseline: 2026-09-29, `feat/0.5.0-beta.5` at `0c9c9490`.

## Release Gate

Run `just check` on the exact commit that will be tagged. It covers the catalog, profiles, schemas, repository tools, DriverKit generation, macOS 14 parsers, formatters, linters, type checks, repository-script tests, and Swift tests. Confirm a clean worktree and run `git diff --check` before tagging.

Publishing, tagging, signing, notarization, and asset upload are separate release actions. A green repository check does not prove any of them.
