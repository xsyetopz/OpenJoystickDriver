# Test WR-007 USB HID receiver

This test covers [OpenJoystickDriver issue #31](https://github.com/xsyetopz/OpenJoystickDriver/issues/31) for USB device `4545:22016` (`11C1:5600` in hexadecimal).

The receiver enumerates as `HORI CO.,LTD.` / `Controller` with one HID interface, 9-byte input reports, and a 4-byte output report. There is no raw-USB/GIP interface. The bundled record keeps Generic HID and maps the observed sparse Xbox-style button usages, Z/Rz right stick, and Simulation Accelerator/Brake analog triggers.

Wireless Guide does not produce an input report. The receiver accepts its advertised output report, but channel probes produced no motor or LED response. Physical rumble stays unavailable.

## Live input

The signing-free USB record probe does not exercise Generic HID element parsing. Use a maintainer-signed build that includes this record.

Connect the USB receiver, then confirm the runtime selects Generic HID for `11C1:5600`:

```bash
/Applications/OpenJoystickDriver.app/Contents/MacOS/OpenJoystickDriver \
  --headless controller list
```

Press each physical control. Confirm face buttons, bumpers, View, Menu, stick clicks, D-pad, both sticks, and analog triggers match the hardware. Guide is not expected. Enable Apple GameController identity and confirm a GameController.framework consumer receives the virtual device.

Do not treat rumble or LED success as part of this request.
