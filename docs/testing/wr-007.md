# Test WR-007 USB HID Receiver

[Issue #31][1]: USB device `4545:22016` in decimal, `11C1:5600` in hexadecimal.

The device calls itself HORI CO.,LTD. / Controller. It has one HID interface, sends 9-byte input, takes 4-byte output, and has no raw-USB or GIP road. The record keeps it on Generic HID and maps:

- its scattered Xbox-style button numbers to buttons
- Z/Rz to the right stick
- Accelerator and Brake to the triggers

The Wireless Guide button sends nothing, so OJD can't see it. Test output reports moved no motor and lit no light, so there's no rumble.

[1]: https://github.com/xsyetopz/OpenJoystickDriver/issues/31

## Live Input

The USB record probe that needs no signing skips Generic HID reading, so use a build a maintainer signed.

1. Plug it in, and check that OJD picks Generic HID for `11C1:5600` (`ojd` is the [command-line tool](../../wiki/Command-Line.md)):

   ```bash
   ojd controller list
   ```

2. Press each control and check that it matches: face buttons, bumpers, View, Menu, stick clicks, D-pad, sticks, and triggers. Guide doesn't work.
3. Turn on the Apple GameController identity. Apps that use GameController.framework should see the virtual gamepad.

Not tested: rumble and lights.
