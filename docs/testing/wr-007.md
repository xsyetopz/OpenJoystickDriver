# Test WR-007 USB HID Receiver

[Issue #31][1]: USB device `4545:22016` (`11C1:5600` hex).

HORI CO.,LTD. / Controller: one HID interface, 9-byte input, 4-byte output, no raw-USB/GIP. The record keeps Generic HID, mapping sparse Xbox-style button usages, Z/Rz right stick, Accelerator/Brake triggers.

The Wireless Guide button sends no input report. Output-report probes got no motor or LED response: no rumble.

[1]: https://github.com/xsyetopz/OpenJoystickDriver/issues/31

## Live Input

The signing-free USB record probe skips Generic HID parsing; use a maintainer-signed build.

1. Connect; check the runtime selects Generic HID for `11C1:5600` (`ojd` is the [command-line tool](../../wiki/Command-Line.md)):

   ```bash
   ojd controller list
   ```

2. Press each control; face buttons, bumpers, View, Menu, stick clicks, D-pad, sticks, triggers match. Guide does not work.
3. Turn on Apple GameController identity; GameController.framework apps see the virtual gamepad.

Not covered: rumble, LED.
