# Test Microsoft Xbox One controller (model 1537)

This procedure covers [OpenJoystickDriver issue #18](https://github.com/xsyetopz/OpenJoystickDriver/issues/18) for USB device `1118:721` (`045E:02D1` in hexadecimal).

The bundled record uses the GIP Xbox One parser, the hardware-reported interrupt endpoints `0x81`/`0x01`, USB configuration 1 before interface claim, and the classic default startup sequence. Reporter packet evidence from an IOUSBHost harness verifies the GIP handshake, player LED, every input including the Guide button, and rumble on this controller.

This hardware result verifies the record and protocol behavior, but not OJD's
current USBDriverKit transport. Record validation is signing-free. The USB and
physical-output checks require an installed, approved, correctly provisioned OJD
application and `com.openjoystickdriver.XboxUSBDevice` extension.

## Validate the bundled record

From the repository root:

```bash
./scripts/ojd diagnose record \
  Sources/OpenJoystickDriverKit/Resources/Controllers/045e/045e-02d1.json \
  --validate-only
```

Expected result:

```text
RECORD_VALIDATION result=valid
```

## Run the USBDriverKit probe

Quit Steam, games, and controller utilities. Connect the controller directly by USB, then run:

```bash
./scripts/ojd diagnose record \
  Sources/OpenJoystickDriverKit/Resources/Controllers/045e/045e-02d1.json \
  --seconds 45
```

Confirm that the controller remains powered and `RECORD_HANDSHAKE` succeeds.
Check that `USB_RX` packets arrive without a user-client, open-device, or transfer
failure.

Test neutral plus press/release for every button, D-pad direction, trigger, stick
axis, stick click, and Guide. Unplug and reconnect the controller. Then repeat the
handshake and a representative control check. If the extension does not claim
the interface, record `./scripts/ojd diagnose dext`; there is no detach fallback.

## Check physical output with an installed app

LED and rumble checks require a separately installed current OpenJoystickDriver app. Use the [physical-output procedure](../physical-output.md) to generate a device-specific plan:

```bash
OpenJoystickDriver --headless controller output list
OpenJoystickDriver --headless controller output plan 1118 721
```

Run each generated step individually. Record the player-indicator result and,
where the plan exposes them, left and right main rumble plus left and right
trigger rumble. This output check does not establish support by itself.

Attach the OJD probe output and physical-output results to issue #18 with macOS
version, Mac model, controller firmware if known, exact OJD and SwifterKit commits,
the installed DEXT identity/version, and results for open, handshake, every
control, reconnect, the indicator, and each exposed actuator. Probe output can
contain raw controller packets; inspect and redact it before publication.

The accepted IOUSBHost packet evidence supports the operational values in this
record. It does not prove that OJD's generated USBDriverKit extension and host
wrapper have passed; that boundary remains pending the retest above.
