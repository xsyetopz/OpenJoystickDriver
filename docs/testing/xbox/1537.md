# Test Microsoft Xbox One Controller (Model 1537)

For [OpenJoystickDriver issue #18][1]: USB device `1118:721` (`045E:02D1` hex).

The record uses the GIP Xbox One parser, interrupt endpoints `0x81`/`0x01`, USB configuration 1 before interface claim, and classic startup. Reporter IOUSBHost harness packets verify the GIP handshake, player LED, every input including Guide, rumble.

This verifies the record and protocol, not OJD's USBDriverKit transport. Validation needs no signing; USB and physical-output checks need an installed, approved, provisioned OJD app and the `com.openjoystickdriver.XboxUSBDevice` extension.

[1]: https://github.com/xsyetopz/OpenJoystickDriver/issues/18

## Validate the Bundled Record

```bash
just diagnose-record \
  Sources/OpenJoystickDriverKit/Resources/Controllers/045e/045e-02d1.plist \
  --validate-only
```

Expect:

```text
RECORD_VALIDATION result=valid
```

## Run the USBDriverKit Probe

1. Quit Steam, games, utilities; connect by USB.
2. Run:

   ```bash
   just diagnose-record \
     Sources/OpenJoystickDriverKit/Resources/Controllers/045e/045e-02d1.plist \
     --seconds 45
   ```

3. Check power holds, `RECORD_HANDSHAKE` succeeds, and `USB_RX` packets arrive without user-client, open-device, or transfer failure.
4. Test neutral, then press and release every button, D-pad direction, trigger, stick axis and click, Guide.
5. Reconnect; repeat the handshake and one control check.

If the extension does not claim the interface, record `just diagnose-dext`; no detach fallback.

## Check Physical Output With an Installed App

Build a plan per the [physical-output procedure](../physical-output.md) (`ojd` is the [command-line tool](../../../wiki/Command-Line.md)):

```bash
ojd controller list
ojd controller show 045E:02D1
```

Run each step alone; record the player indicator and planned left, right, trigger rumble. Not proof of support.

Attach to issue #18: macOS version, Mac model, firmware if known, exact OJD and SwifterKit commits, installed DEXT identity and version, probe output, and results for open, handshake, every control, reconnect, the indicator, each exposed actuator. Probe output may hold raw packets: redact before publishing.

IOUSBHost packets support the record's values, not OJD's generated USBDriverKit extension and host wrapper (pending this retest).
