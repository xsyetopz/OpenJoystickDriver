6. Why OJD leaves the pad to macOS (source of the branch):
- HIDDeviceStream+DeviceLifecycle.swift:98-104: nativePassThrough = GCController.supportsHIDDevice(device)
  and the record's server is not OJD (DeviceCatalog.swift:48-50).
- HIDDeviceStream+DeviceLifecycle.swift:66: a native-pass-through device is not seized.
- DeviceCatalog.swift:96: a record with no server gets `.system`.
- DeviceManager+DiscoveryModels.swift:90-94: native pass-through is reported as `.systemGamepad`.
- ServingPolicy.swift:145-149: served by the system, server `.system`, access route `.system` gives the route
  `.nativePassThrough`, so OJD publishes no gamepad.
- HIDDeviceStream+DeviceLifecycle.swift:80: `systemListsGameController` is the same supportsHIDDevice answer.
  It drives the `ojd controller list` warning of step 2 ("The system also lists this controller as a second
  controller that gives no input"), which is wrong for this pad: GameController lists none.
