=========================================================================

Mac: macOS 27.2, build 26B123. Date: 2026-11-11. App: /Applications/OpenJoystickDriver.app,
0.6.0-alpha.2 (build 1.21.99), process "OpenJoystickDriver", already running.
Method: `osascript` with System Events, the command forms of
`apple-apps-accessibility.txt`. Each command reads roles, descriptions, names,
and sizes. A screenshot of each window, area, and pane is in `ojd-alpha2/`; each
captures only OJD's window (`screencapture -x -o -l <windowID>`). Sizes are
width x height in points. A window size is the frame the window had when read,
not the default: the main window was 960x588.
State when read: one 8BitDo Ultimate 2C Wireless connected over Bluetooth Low
Energy, and the receiver-like device `2dc8:301c` (USB) listed with no controls.
An earlier baseline (`ojd-alpha2/main-Controllers-baseline-0-connected.png`)

Every area was selected with the View menu, the way `shoot.sh` does:

    osascript -e 'tell application "System Events" to tell process "OpenJoystickDriver" to click menu item "<Area>" of menu 1 of menu bar item "View" of menu bar 1'

1. Main window: toolbar (one reading per area)
----------------------------------------------

Command (after selecting the area; groups are read one level down):

    osascript -e 'tell application "System Events" to tell process "OpenJoystickDriver"
    set out to ""
    repeat with e in (UI elements of toolbar 1 of window 1)
    set s to size of e
    set out to out & (role of e) & " | " & (description of e) & " | " & (item 1 of s) & "x" & (item 2 of s) & linefeed
    if role of e is "AXGroup" then
    repeat with c in (UI elements of e)
    set cs to size of c
    set out to out & "    " & (role of c) & " | " & (description of c) & " | " & (item 1 of cs) & "x" & (item 2 of cs) & linefeed
    end repeat
    end if
    end repeat
    set ws to size of window 1
    return out & "window " & (item 1 of ws) & "x" & (item 2 of ws) & " title " & (title of window 1)
    end tell'

2. Main window: sidebar, list, detail
-------------------------------------

Command:

    osascript -e 'tell application "System Events" to tell process "OpenJoystickDriver"
    set out to ""
    set c to entire contents of window 1
    repeat with i from 1 to count of c
    set e to item i of c
    try
    set s to size of e
    set d to ""
    try
    set d to description of e
    end try
    set n to ""
    try
    set n to name of e
    end try
    set out to out & (role of e) & " | " & d & " | " & n & " | " & (item 1 of s) & "x" & (item 2 of s) & linefeed
    end try
    end repeat
    return out
    end tell'

(`entire contents` is read into a list first and walked by index: a
`repeat with e in (entire contents ...)` returns nothing here.) Text values
other than labels, and repeated AXStaticText lines, are left out below.
