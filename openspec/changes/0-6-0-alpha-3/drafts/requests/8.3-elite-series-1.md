Thanks for the report on issue #55. Pull request #56 found that interface 0 of the Xbox Elite Series 1 (`045E:02E3`) has interrupt IN `0x81` and OUT `0x01`, as the `045E:02D1` record has. The GIP defaults `0x82` and `0x02` are isochronous endpoints of interface 1 on this controller. The `045E:02E3` record now uses `0x81` and `0x01`. No hardware run has confirmed this yet, and the pull request notes that the handshake still failed with `kIOReturnBadArgument` on 0.6.0-alpha.2, so the controller may still not work. Could you test it on a tester build?

1. Install the tester build I send you, as [Test a tester build](https://github.com/xsyetopz/OpenJoystickDriver/blob/main/docs/testing/tester-builds.md) shows.
2. Plug the Elite Series 1 in by cable and run:
   ```
   ojd controller list
   ojd controller show 045E:02E3
   ```
3. Press each control once while this runs:
   ```
   ojd controller watch 045E:02E3 --duration 60
   ```
4. Run this and tell me whether the pad vibrates and the service stays up:
   ```
   ojd controller rumble 045E:02E3 --left 100 --right 100 --duration 2
   ```
5. If the handshake fails, run this and attach the file. Read it before you share it.
   ```
   ojd diagnose --output support-02e3.txt
   ```
6. Tell me which controls work, and the exact error text if one appears (for example `kIOReturnBadArgument`).
