# Changelog Entries For Task 18.1

Entries the task workers wrote, held here until task 18.1 writes `CHANGELOG.md`.

## Added

- The endpoint takes a `ProfileRequest` line with the `Control` scope to activate, deactivate or set one value of a remapping profile, and answers a `ProfileResult`. A refusal by the service is a `Status` failure with the code that `ojd` prints and keeps the connection open. Shortcuts lists a Set Profile Value action that does the same as `ojd profile set`. See the [endpoint protocol](docs/sdk/endpoint.md#profilerequest). (6.11)
- The endpoint takes a `ModList` line with the `Read` scope and answers `Mods`, the installed mod packages, as `ojd mod list --json` does. Shortcuts lists the actions List Mod Packages, Install Mod Package and Remove Mod Package, which run the code of `ojd mod list`, `install` and `remove`. See the [endpoint protocol](docs/sdk/endpoint.md#modlist). (6.12)
- The endpoint takes an `OutputRequest` line with the `Control` scope to rumble a controller, set its player number, or set its light, and answers `OutputResult`. Shortcuts lists the actions Rumble Controller, Set Player Indicator and Set Controller Light. Both run the code of `ojd controller rumble`, `player` and `light`, and refuse an output that the controller lacks with the code that `ojd` prints. See the [endpoint protocol](docs/sdk/endpoint.md#outputrequest). (6.13)
- The endpoint takes the `Subscription` streams `Profiles` and `Mods` beside `Controllers`, with the `Read` scope. Each sends the whole list at once and again each time it changes, as a `Profiles` or a `Mods` line. See the [endpoint protocol](docs/sdk/endpoint.md#subscription). (6.14)

- `ojd generate <script> [--output <folder>] [--replace] [--timeout <seconds>]` runs a JavaScript file's `generate` function in a helper process with no file or network access, checks every document it returns with the reader for its kind, and writes the files with the store's names. It writes nothing when one document fails, reports the document, key path and rule, reports a script error with its line, leaves an equal file unchanged, and stops at a differing file unless `--replace`. See [Generating Documents with Scripts](wiki/Generating-Documents-with-Scripts.md). (6.1–6.5, 6.8)
- A mod package skips its `.js` files and never runs them. (6.6)
- A description document in `Protocols/` can name a protocol family that OJD lacks, with an UpperCamelCase name and `defaults.input.layouts`; a record that names the family decodes its reports with those layouts. The family loads from the user's `Protocols/` folder and from a mod package, takes its display name from the document, and is refused when its name equals a built-in family, when it has no input layouts, or when its file stem differs from its name. (9.19, 9.20)
- `ojd protocol validate <file>`, `ojd protocol install <file> [--dry-run]` and `ojd protocol list`, which lists the built-in and documented families with their source (`BuiltIn`, `User` or `Package`). (9.21)
- The wiki page [Support Ladder](wiki/Support-Ladder.md) lists the five ways to support a controller (nothing, a patch, a record, a generator script, source) with the command for each and a complete patch and record; `llms.txt` and `llms-full.txt` list the same steps. (9.10)
- The Xbox Elite Series 1 (`045E:02E3`) record uses its interface 0 endpoints, interrupt IN `0x81` and OUT `0x01`, as the `045E:02D1` record does. The GIP defaults `0x82` and `0x02` are isochronous endpoints of interface 1 on this controller. Hardware confirmation is pending. Thanks to Kurtis Simpson (#56). (8.3)
- The Turtle Beach / PDP Xbox Rematch Advanced Wired Controller (`10F5:711E`) has an `XboxGIP` record with interrupt IN `0x81`, OUT `0x02` and `SetConfiguration1BeforeClaim`. The contributor's run on macOS 26.6.2 decoded the face buttons, D-pad, sticks and triggers; rumble and the player indicator are not claimed. Thanks to phil-bbs (#57). (8.8)
- The PowerA XBX Spectra Enhanced Wired Controller (`20D6:4002`) has an authored `XboxGIP` record, so the model no longer depends on the Linux import. Thanks to Anonim0_Venezian0 (#50). (8.9)
- The Razer Wolverine V3 Tournament Edition (`1532:0A43`) uses interrupt IN `0x81` and OUT `0x01` through a bundled patch. The contributor reports a successful handshake, the LED on, and working buttons, sticks, triggers and D-pad. Thanks to Mason (#39). (8.10)
- A record for the Thrustmaster Ferrari 458 Spider wheel (`044F:B671`) uses the `XboxGIP` driver with an input layout: steering is Left Stick X (16 bits at report bytes 6 to 7) and the brake is Left Trigger (10 bits at bytes 10 to 11), checked with `ojd record test` on the packets of [#58](https://github.com/xsyetopz/OpenJoystickDriver/issues/58). Only the reporter's rest, left-turn and accelerator packets are checked: the brake, the clutch, every other button and the turn to the right are not captured. (8.4)
- `ojd controller show VVVV:PPPP` resolves a connected device that OJD does not serve and prints the reason and the next step, a Draft a record row with `ojd record draft` for a HID gamepad, and for `no-protocol-match` the capture command; `--json` has `kind` `UnservedController`. Selecting such a device in the Controllers list opens the same reason and next step, with Draft Record for a HID gamepad. (9.8)

## Changed

- Every reason OJD does not serve a connected controller, `interface-contract-mismatch` included, has a sentence that says why and a next step in every language. The Controllers list and `ojd status` show both, and a test fails on a reason with no sentence. (17.2)
- The app sends the driver extension activation request only after a user action: the banner button, the **Claim** button, `ojd controller claim` for a model that Apple's driver holds, or `ojd transport-extension activate`. Launch, service start and a controller arrival send none. (4.3, 4.5)
- A controller on a model that Apple's driver holds (`045E:02EA`, `045E:0B00`, `045E:0B12`) is listed as served by macOS, with **Claim**, in the Controllers list and in `ojd controller show` (`served-by` and `heldByAppleDriver`). The Microsoft models `045E:02D1`, `045E:02DD`, `045E:02E3` and `045E:0B0A` take the direct route when the extension does not own them. (4.2, 4.4)
- The driver banner shows each state of the request: running with a disabled button, needs approval with a button that opens the approval pane, cancelled, timed out, and failed with the error domain, code and text. It shows only while a connected controller uses the extension route. (4.6)
- The wiki heading `extension` is `transport-extension`. (4.7)
- A controller session reports its input as `AwaitingInput` (`awaiting-input` in `ojd controller show`, "Waiting for the first input..." in the controller detail) until its first input report, and `Healthy` after it. (3.3)

- `ojd migrate [FOLDER]` converts the documents an earlier alpha wrote (`v1alpha1` and `v1alpha2` JSON) to `v1alpha3` property lists, gives each file one verdict (`Migrated`, `Current`, `Failed`, `Foreign`), keeps each original under `Migrated/`, never overwrites a backup, and exits `E5009` when a file failed. `--dry-run` writes nothing. A file that OJD 0.5 wrote fails with "re-create it". (5.2, 5.3, 5.4, 5.6)
- The service migrates the stored documents when it starts, before any store opens, and logs each verdict. (5.5)
- The app offers Migrate wherever it reports `E5001`, and the Profiles area names an earlier alpha's `.json` profile. (5.7)
- The implementation status and `Scripts/SDK/reference_client.py` name `openjoystickdriver/v1alpha3`. (18.4)
- A controller record's `input.layouts` applies under every protocol family: a layout decodes the controls it names in the reports it selects, and the family's decoder reads the rest. A `HIDDescriptor` mode refuses a layout. (9.2)
- A controller patch may set every record property except the identity, including `capabilities`. `patch.modes` merges by `id`: an entry with a known `id` changes that mode, a new `id` adds a mode, and the `remove` path `modes.<id>` drops one. A record's `capabilities` may name a control that the driver of any of its modes declares. `ojd migrate` gives a `v1alpha2` patch that sets `modes` the `remove` path `modes`, so it still replaces the record's modes. (9.15)
- **Breaking:** a profile's `applicationScope` holds `appIDs`, a list of one or more bundle identifiers, and the profile applies while any of those apps is in front. A document with `appID` is refused with a named error, and `ojd migrate` converts it, `ActiveProfiles` entries included. `ojd profile create` and `ojd profile import` take `--app` more than once; on import it replaces the scope in the file. (15.1)
- The wiki, the README and the `llms` files show every document example as an XML property list and give the `plutil -convert` commands in both directions. `ojd record install --help` names a `.plist` file. (18.3)
- The controller detail's Advanced section shows the Capture Packets, Draft Record and Draft Record from SDL buttons in one row, in a column when the row does not fit. Its parser, input mapping and control rows say the name in words and keep the raw identifier beside it, such as `Xbox 360 (XUSB), Receiver (xbox-xusb:receiver)` and `D-pad up (DpadUp)`. (12.18)
- `ojd record draft VVVV:PPPP` drafts a record for every connected controller, served or not; `E2012` is for a controller that is not connected. A device with a HID gamepad interface gets a `HIDDescriptor` mode, as a patch when a bundled record holds the model (#63). A device with only vendor-class interfaces gets its identity and one mode for each interface signature, and the command names the `input` section as missing (`missingSections` in `--json`). (9.16)
- **Breaking:** `idle` is a key of a mode, not of a record, and its value names the reason: `NoControllerLinked` or `Bootloader`. A mode with `idle` serves nothing, has no `interface` or `session`, and a record of only idle modes has no `usb`, `bluetoothLE`, `capabilities`, `server`, `route`, `input` or `tuning`. A record or patch with `idle: true` is refused with `E5007`; `ojd migrate` moves it to the `default` mode as `NoControllerLinked`. `ojd status` and the Controllers page report `NoControllerLinked` where they reported `IdleIdentity`. (9.3)
- The menu bar menu lists one row per connected controller, then Open OpenJoystickDriver, Settings and Quit. A row shows the controller name with its battery level, active profile and paused state, and opens one submenu with a checkmarked profile list ending in No Profile (More Profiles after ten, which opens the Profiles area), Pause or Resume, Test Input, Show in Window and, for a wireless controller, Disconnect Wireless Link. With no controller the menu shows a disabled "No Controller Connected" row. The Controllers, Profiles, Activate, Deactivate and Help submenus, the joined status line and the Activity Log, Explain Error Code, Report Problem and Project Website items are removed from this menu; the main menu's Help menu keeps them. (11.1, 11.2)
- Input Test applies the player indicator when you choose it and has no Apply button for it. A note under the rumble motors says their levels are sent when you click Test Rumble. A rumble, player indicator, color or brightness test that cannot be sent, because the controller is disconnected or lacks the output, shows a failure with the reason. (12.1)
- The **Served by** picker is unavailable while its request runs and shows progress below it, shows the service's refusal directly below it, and is unavailable with the reason when no controller record describes the controller's model. (12.2)
- The **Virtual HID profile** pop-up lists only the kinds the service accepts for the controller, names the kind in use and the stored override when they differ, and shows as text why a choice sends nothing: already in place, or the override in effect is stored in the other scope. (12.3)
- The stick dead zone editor writes the last value you set while a write runs, including a reset, after that write ends, instead of dropping it. (12.4)
- The profile editor and list say why an edit, save, create, import or delete is refused, show "Unsaved changes" beside Save, and say when choosing a virtual gamepad turns off exclusive physical input. (12.5)
- Settings gives the reason Start at login cannot change, says when macOS has denied notifications and offers the Notifications pane of System Settings, checks for updates at once when Automatic update check is turned on, and names the controller that needs attention in the "Connected" notification switch. (12.6)
- A failed packet capture export shows its reason under the Export button, and a failed Activity action shows a row with Dismiss at the top of the Activity area, instead of an alert. (12.7)

- The main window's minimum width is the sum of the minimum widths of the columns it shows: 790 points with the sidebar, list and detail (it was 960), 620 with the sidebar hidden, and 590 in Access and Activity, which have no list column. The window grows when a column returns and the window is too narrow for it. (12.10)
- Every action of the main window's toolbar has a menu command with the toolbar item's title, available while the item is shown and enabled: File has Validate..., Test Record..., Remove, Grant a Program..., Create a Token... and Show in Finder; Edit has Copy All; View has Activity, Filter and Run Checks; Profile has New profile, Duplicate, Delete and Validate profile file. Import, Export, Install Record or Mod and Save Activity Log keep their File items, and the two search fields are reached by Find. (12.8)
- Edit has Find with Command-F, which moves the keyboard focus to the search field of the Library list or the Activity log. It is unavailable in the other areas, in Activity's diagnostics view, and while the toolbar is hidden. (12.9)

## Fixed

- A GIP pad that announces nothing and sends its first report to an input read that is already pending gets that read before the startup writes. Not checked on hardware. (3.2)
- A transfer on an interrupt pipe through the driver extension passes timeout 0, which the pipe requires, so the Xbox Elite Series 1 no longer fails with `kIOReturnBadArgument` ([#55](https://github.com/xsyetopz/OpenJoystickDriver/issues/55)). Not checked on hardware. (8.1)
- A USB session start that keeps failing its handshake stops after 5 failures in a row, and the controller shows the last error ([#55](https://github.com/xsyetopz/OpenJoystickDriver/issues/55)). (8.2)
- OJD no longer seizes the HID device of a model that a record serves over raw USB or the extension, so it leaves that device to other apps such as Steam ([#18](https://github.com/xsyetopz/OpenJoystickDriver/issues/18)). Not checked on hardware. (9.17)
- The 8BitDo Ultimate 2C receiver `2DC8:301C` idles only while its product string is `IDLE` and serves the HID descriptor once a pad is linked ([#34](https://github.com/xsyetopz/OpenJoystickDriver/issues/34)); it maps no named control yet. Not checked on hardware. (2.4)
- The 8BitDo bootloader identities `2DC8:3208` and `2DC8:5750` have bundled records that idle with the reason `Bootloader`, and a user or package file that adds or patches either is refused. (9.4)
